# Quantitative Structure-Property Relationship (QSPR) Analysis of Polyphenols

## Overview
This repository contains the complete dataset, Python scripts, and calculated results for our Quantitative Structure-Property Relationship (QSPR) research. This study investigates the physicochemical properties of 47 polyphenol compounds using pure, mathematically independent vertex-degree-based Sombor indices. 

The primary goal of this research is to establish a mathematically sound framework that prioritizes data purity and strict feature selection over complex algorithmic processing. 

## Methodology
To ensure high accuracy and prevent statistical errors, our mathematical process follows a strict four-step framework:

1. **Feature Calculation:** We computed seven distinct vertex-degree-based Sombor indices for all 47 polyphenol compounds in our dataset.
2. **Feature Selection:** We applied the Variance Inflation Factor (VIF) to identify and eliminate highly overlapping variables. This step isolated the Exponential (ESO) and Modified Exponential (MESO) indices as the most independent structural descriptors.
3. **Predictive Modeling:** Using these two refined features, we compared the predictive power of regularized linear models (Ridge and Lasso Regression) against advanced machine learning algorithms (Random Forest and XGBoost).
4. **Validation:** Every model was rigorously evaluated using Leave-One-Out Cross-Validation (LOOCV). We measured performance using $R^2$ Scores, Root Mean Squared Error (RMSE), and Mean Absolute Error (MAE).

## Repository Structure

Our files are organized into three main folders to ensure this research is fully transparent and reproducible for other mathematicians and researchers:

### `/Data`
This folder contains the foundation of our research.
* `dataset.xlsx`: The raw data file containing the laboratory-tested values for the 10 physicochemical properties across all 47 polyphenol compounds.

### `/Code`
This folder holds the Python scripts required to reproduce our mathematical models and statistical tables.
* `indices.txt`: The Python script designed to calculate the Sombor-based topological indices directly from the chemical data.
* `table.txt`: The Python script used to generate the descriptive statistics, calculate the VIF scores, and output the Pearson correlation matrix.
* `Models.txt`: The Python script responsible for training the Ridge, Lasso, Random Forest, and XGBoost models.
* `Predictions.txt`: The Python script that generates the final actual versus predicted values for every single compound.

### `/Results`
This folder contains the final output files and supplementary tables generated by our code, formatted cleanly for academic review.
* `table1_descriptive_statistics.csv`: The mathematical spread and summary of the target properties.
* `table2_correlation_matrix.csv`: The matrix demonstrating the overlap between the seven initial indices.
* `table3_vif_scores.csv`: The exact scores confirming the mathematical independence of the selected ESO and MESO features.
* `calculated_sombor_indices.csv`: The raw computed topological indices for the dataset.
* `actual_predictions_ready_for_paper.csv`: The side-by-side comparison of actual laboratory values against our models' predictions.

## Usage and Reproducibility
Researchers are encouraged to download the scripts from the `/Code` folder to replicate our machine learning models. By running `table.txt` followed by `Models.txt`, users can observe the data cleaning process (VIF) and the subsequent LOOCV training process for the predictive models.
